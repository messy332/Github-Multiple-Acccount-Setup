# Github-Multiple-Acccount-Setup
Step-by-step setup guide for using Personal and Institutional GitHub accounts on one OS with SSH authentication and Git configuration.

## Environment

- <strong>Operating System:</strong>      Windows 11
- <strong>Git Version:</strong>           2.53.0.windows.2
- <strong>GitHub Accounts:</strong>       Personal + Institutional
- <strong>Authentication Method:</strong> SSH Keys
