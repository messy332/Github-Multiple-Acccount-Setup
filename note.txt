STEP1 — CHECK IF GIT IS INSTALLED
Open terminal (OS / VS Code terminal):
                                      git --version


STEP2 — CREATE SSH KEYS FOT BOTH ACCOUNTS
PERSONAL ACCOUNT: 
                 ssh-keygen -t ed25519 -C "personal_email@gmail.com"
Save it as:
            ~/.ssh/id_ed25519_personal
INSTITUTIONAL ACCOUNT:
                      ssh-keygen -t ed25519 -C "school_email@school.edu"
Save it as:
           ~/.ssh/id_ed25519_school


STEP3 — ADD SSH KEYS TO SSH-AGENT
START AGENT:
            eval "$(ssh-agent -s)"
            ssh-add ~/.ssh/id_ed25519_personal
            ssh-add ~/.ssh/id_ed25519_school
CHECK: 
      $ ssh-add -l


STEP4 — ADD SSH KEYS TO GITHUB
Show your public keys:
PERSONAL:
          cat ~/.ssh/id_ed25519_personal.pub
SCHOOL:
          cat ~/.ssh/id_ed25519_school.pub
ADD THEM HERE:
              PERSONAL - https://github.com/settings/keys
              SCHOOL -  https://github.com/settings/keys (logged into institutional account)
Click “New SSH Key” and paste each one.


STEP 5 — CREATE SSH CONFIG FILE
Open config file:
                  nano ~/.ssh/config
PASTE THIS:
# Personal GitHub
Host github-personal
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_personal
# Institutional GitHub
Host github-school
    HostName github.com
    User git
    IdentityFile ~/.ssh/id_ed25519_school
Save:
     CTRL + X
     Y
     Enter

STEP 6 — TEST CONNECTIONS
PERSONAL:
        ssh -T git@github-personal
SCHOOL:
        ssh -T git@github-school
You should see:
               Hi username! You've successfully authenticated

STEP 7 — USE CORRECT ACCOUNT PER PROJECT
PERSONAL REPOSITORIES:
              git clone git@github-personal:username/repo.git
SCHOOL REPOSITORIES:
              git clone git@github-school:username/repo.git

STEP 8 — SET IDENTITY PER PROJECT
Inside each project folder:
PERSONAL PROJECT:
                  git config --global user.name "Your Name"
                  git config --global user.email "personal@gmail.com"
SCHOOL PROJECT:
                  git config --global user.name "Your Name"
                  git config --global user.email "school@gmail.com"
NOTE DON`T USED: 
                git remote add origin https://github.com/...

USED: 
     git remote add origin git@github-personal:username/nameproject

     git remote set-url origin git@github-personal
     git remote set-url origin git@github.com:username/nameproject
     git remote set-url origin https://github.com/username/nameproject
TROUBLESHOT: 
$ ls -la ~/.ssh
